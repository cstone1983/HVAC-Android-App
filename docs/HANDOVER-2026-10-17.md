## What changed

### Solar tab — numbers now come from Solar Calc
- `GET https://solar.stoneyshome.com/api/app/v1/today` (LAN `http://10.10.1.156:8080/`). Contract
  version 1. `SolarCalcApi.kt`, `SolarCalcClient.kt`, `SolarTodayState.kt`, `SolarTodaySection.kt`,
  `SolarWeekSection.kt`.
- **The app calculates nothing from it** — not even a percentage. Tiles arrive pre-worded. This is
  the point: the app used to sum power readings ÷ 6000 (assuming 10-minute spacing) and ran ~2%
  high every day (98.0 vs the site's 95.7). Deleted.
- Three tiles (Right now / Today so far / By midnight), Today chart with the model forecast dashed
  over measured generation, treeline shading, now line, tap readout.
- `week` block (added to the reply without a version bump): week-ahead chart and "what the week
  costs you" table. Laid out by **window width**, not model: <600 dp stacked/short labels,
  ≥600 dp full labels, ≥840 dp side by side. Selected day in `rememberSaveable`.
- Removed: GRID STATUS card (it showed whole-house use, not grid), TODAY'S GENERATION/USAGE cards,
  and the importing/exporting NetMeterCard banner (Chris: redundant with Right now). NetMeterCard
  is still in the file if wanted back — it was live off the WebSocket, the tile is a 5-minute sample.
- OTA: `solarCalc` block — `enabled`, `baseUrl`, `pollSeconds`, ten colour tokens. Polls only while
  the solar tab is visible.
- Tests: `SolarTodayParsingTest`, `SolarWeekParsingTest` against a **real captured reply**
  (`src/test/resources/solar_today_v1.json`). Tests assert shape, not values — the fixture gets
  refreshed and the weather changes.

### Alarm
- **Device Mode** (Settings → System Engines): Wall panel / Phone. Replaces the scattered siren /
  beep / wake / notify flags. `model/DeviceMode.kt`. Panel: siren, forced volume, screen wake.
  Phone: notifications only. Both: countdown beeps. Resolution: explicit choice → old
  `alarm_siren_enabled` pref → model number.
- **Siren moved into `HvacForegroundService`** (was in MainActivity's composition, so a panel whose
  activity was torn down never sounded — the A9 incident). Generated square-wave wail, not the
  device alarm tone.
- **Countdown beeps** on entry (exit opt-in, `alarm.exitBeep`). Accelerating tiers 1000/500/250 ms.
  Synced across panels via `HaClock` (offset from HA's own timestamps, min over a rolling window)
  and measured from HA's `last_changed`, not each device's start time. The two tablets' clocks were
  ~284 ms apart.
- **Notifications, phone only:** triggered (alarm stream, passes DND, full-screen intent, alert-beep
  WAV) and status (`alarm.notifyEvents`, default `["armed"]`).
- **Keypad on the A9** took four attempts. Final state: card height capped from `screenHeightDp`,
  disarm row pinned outside the scroll, keys sized to the screen (A9 ≈ 51 dp, others 65 dp),
  counter shrinks on short screens. Typing lag fixed by moving the idle timer off Compose state and
  deferring the masked-code read. Disarm button reads CHECKING… while Alarmo validates the code —
  that pause is Alarmo, not the network or the app.
- Night mode `trigger_time` set to 1800 by Chris (was 0 — triggered and stopped instantly).

## Things that bit

- **adb: connect by mDNS name, not IP:port.** `adb connect 10.10.1.x:port` is refused while
  `adb-XXXX._adb-tls-connect._tcp` works. Several "devices unreachable" conclusions were this.
  Pairing is permanent; only re-pair after a revoke/reset. Pairing port ≠ connect port.
- **Verify the state that broke.** The keypad was "fixed" twice against the armed-house keypad,
  which has no countdown and is ~70 dp shorter. Arm the house and look at the real thing.
- **Measure before shrinking.** The keypad fix that worked came from measuring the chrome
  (294 dp) against the card (505 dp) from a screenshot.
- **`fillMaxSize` inside a Dialog** measures the dialog's window, which wraps its content.
- **Moshi `Map<String, Double?>`** failed the whole reply on one boolean (`generation_done`).
- **Backticks in a double-quoted bash string** execute. Write files with the Write tool or a quoted
  heredoc.
- **Windows Python can't see bash's `/tmp`**, and `urllib` is 403'd by the solar site — use curl.
- **Statistics vs history:** a sensor with no `state_class` has no statistics even when healthy.
- **Read ambiguous instructions both ways.** "Leave the goodnight and house off" meant remove them.
